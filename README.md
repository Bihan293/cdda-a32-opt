# CDDA A32 — pure performance build

Сборка **Cataclysm: Dark Days Ahead** (experimental, master) для Samsung Galaxy A32 (SM-A325F, Helio G80, Android 13).

Это **не перебалансированная и не урезанная версия**. Мир, размер городов, количество NPC, пузырь реальности, анимации, звук, управление и все настройки остаются штатными. Меняются только компиляция, код отрисовки и память.

## Что именно изменено

1. **Компилятор**: release-сборка с `-O3` вместо штатного `-Os -g`, `-fno-semantic-interposition`, `-march=armv8-a -mtune=cortex-a75`, без debug-символов. Код тот же, поведение то же.
2. **Не отдавать кадр, если ничего не изменилось**. Игра вызывает `refresh_display()` из опроса ввода 10 раз в секунду и в некоторых других местах, даже когда UI не перерисовывался. На Android это полный `ClearScreen` + копирование буфера + `SDL_RenderPresent` для идентичной картинки. Теперь такой кадр пропускается. Любое реальное изменение (нажатие, редроу, смена меню, джойстик) по-прежнему выставляет `needupdate` и отрисовывается.
3. **Сон**: убран лишний present из 10-герцового цикла опроса ввода. Прогресс-попап сна/чтения/крафта всё равно обновляется, ввод (включая пробуждение) работает. Это не меняет симуляцию и не меняет игру — только частоту показа одного и того же экрана.
4. **`largeHeap="true"`**: процессу разрешено держать в памяти атлас тайлсета и большой сейв на 4 ГБ телефоне.
5. **Русский перевод**: в APK добавлен официальный `ru.po` из экспериментального релиза CDDA (в git-репозитории CDDA переводы не хранятся, официальная сборка тянет их из Transifex). Остальные языки — как в исходнике.

Чего здесь **нет**: уменьшения `MAPSIZE`, изменения `city_size`/`city_spacing`, уменьшения числа NPC, отключения анимаций/звука, смены шрифта, джойстика, автосейвов или каких-либо игровых дефолтов. Всё это остаётся как в официальной CDDA.

## Честно про «100x»

100x без изменения симуляции — это не флаги компилятора, а переписывание горячих циклов движка. Чистая оптимизация даст умеренный выигрыш: `-O3` и пропуск пустых кадров обычно дают единицы–десятки процентов, иногда больше, если узким местом был именно рендер. Пятиминутные сны/чтение/крафт в основном упираются в пошаговую симуляцию NPC, огня и предметов; чтобы ускорить их без «кастрации», нужно профилировать и оптимизировать конкретные горячие функции (NPC AI, обработка полей/предметов, кеши карты). Это следующий этап — уже по замерам, а не наугад.

## Установка

1. Скачай APK из [Releases](../../releases) (или из последнего успешного Actions run).
2. Разреши установку из неизвестных источников.
3. Установи APK.

Пакет: `com.cleverraven.cataclysmdda.experimental`. Подпись своя, поэтому APK не обновится поверх официальной experimental с другой подписью. Если официальная experimental уже стоит — сохрани сейвы и удали её перед установкой. Со стабильной версией (`com.cleverraven.cataclysmdda`) они сосуществуют.

Данные игры: `Android/data/com.cleverraven.cataclysmdda.experimental/files/`. Перед удалением старой версии скопируй `save/`.

## Пересборка

Actions → **Build CDDA A32 optimized APK** → Run workflow. Параметр только один: `cdda_ref` (ветка/тег/коммит, по умолчанию `master`).

## Подпись

APK подписывается ключом из GitHub Secrets. Если ключ потерять/сменить, новые сборки не установятся поверх старых — придётся удалять игру и восстанавливать сейвы. Локальный бэкап ключа хранится вне репозитория.
