# CDDA A32 Optimized

Сборка **Cataclysm: Dark Days Ahead** (experimental, master) для Samsung Galaxy A32 (SM-A325F, Helio G80, Android 13).

Собирается автоматически в GitHub Actions из официального исходника CleverRaven. В репозитории лежит только скрипт патчей и workflow; сам исходник CDDA не копируется.

## Что изменено

**Скорость симуляции**

- `MAPSIZE` уменьшен с 11 до 7 (пузырь реальности 132×132 → 84×84 тайла, примерно в 2,5 раза меньше области симуляции). Дальность действий и стрельбы ограничена 36 тайлами вместо 60.
- Города по умолчанию меньше и реже: `city_size` 8 → 4, `city_spacing` 4 → 8.
- Случайные NPC появляются редко: `npc_spawntime` 4 → 30 дней. Статические NPC и сюжетные встречи остаются.
- `FORCE_REDRAW` выключен: игра больше не перерисовывает и не отдаёт кадр каждый ход.
- Во время сна кадр не отдаётся 10 раз в секунду; прогресс обновляется раз в 5 игровых минут.
- Автосохранение реже: 500 ходов / 30 реальных минут вместо 50 / 5.

**Рендер и интерфейс**

- Анимации, дождь, снаряды и боевой текст выключены по умолчанию; задержка анимации 0.
- Звук выключен по умолчанию.
- Текст Android: `12x24` вместо `auto` (auto подбирает 8×16 под 80 колонок на 720p — поэтому интерфейс был микроскопическим). Примерно 60 колонок, читаемо.
- Виртуальный джойстик крупнее и заметнее (`scale 1.30`, `opacity 35`).
- `largeHeap` в манифесте — больше шансов не получить OOM на большой графe/модах.

**Компиляция**

- Release-сборка: `-O3` вместо `-Os -g`, `-fno-semantic-interposition`, `-march=armv8-a -mtune=cortex-a75`, без debug-символов.
- Только `arm64-v8a`, релизная подпись своим ключом.

## Установка

1. Скачай APK из [Releases](../../releases) (или из последнего успешного Actions run).
2. Разреши установку из неизвестных источников для браузера/файлового менеджера.
3. Установи APK.

Пакет: `com.cleverraven.cataclysmdda.experimental`. Он не конфликтует со стабильной версией `com.cleverraven.cataclysmdda`, но **не обновится поверх неё** из-за другой подписи. Если официальная experimental уже стоит — сохрани сейвы и удали её перед установкой.

Данные игры лежат в `Android/data/com.cleverraven.cataclysmdda.experimental/files/`. Перед удалением старой версии скопируй папку `save/` в надёжное место.

## Настройки и компромиссы

Все изменения — это дефолты для **нового** мира и новой установки. Уже существующие миры не перегенерируются. В игре всё можно поменять:

- Options → Graphics → Animations (вернуть анимации);
- Options → General → Sound enabled (вернуть звук);
- Options → Android → Text size / Joystick scale;
- Options → Graphics → Force redraw (вернуть перерисовку каждый ход, будет медленнее).

Уменьшенный пузырь реальности означает, что объекты дальше ~36 тайлов не симулируются, пока ты не подойдёшь. Для одиночной игры это обычно незаметно, но это осознанный компромисс.

**Про «100x»:** гарантировать ускорение в 100 раз нельзя — это потребовало бы переписать движок. Цель этой сборки — убрать самые дорогие накладные расходы (рендер каждого хода, огромные города, лишние NPC, симуляция 132×132) и дать кратный рост там, где сейчас минуты уходят на сон/чтение/крафт. После установки нужно замерить на реальном сейве.

## Пересборка

Actions → **Build CDDA A32 optimized APK** → Run workflow.

Параметры:

- `cdda_ref` — ветка/тег/коммит CDDA (по умолчанию `master`);
- `bubble` — `7` (быстро) или `9` (безопаснее, если 7 ломает генерацию);
- `variant` — `performance` или `balanced`.

## Подпись

APK подписывается ключом из GitHub Secrets. Если ключ потерять/сменить, новые сборки не установятся поверх старых — придётся удалять игру и восстанавливать сейвы. Секреты репозитория не публикуются; локальный бэкап ключа хранится вне репозитория.
